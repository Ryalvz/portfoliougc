Política de Privacidade

Painel Ryan Alves · atualizada em 9 de outubro de 2026

O Painel Ryan Alves é um painel pessoal, usado só pelo criador de conteúdo Ryan Alves (heyryan.ugc@gmail.com) para organizar o próprio trabalho: propostas de marcas, campanhas, financeiro, calendário e métricas das próprias redes sociais. Ele não é oferecido ao público e não tem outros usuários.

Quais dados o painel acessa

  • Gmail (heyryan.ugc@gmail.com): o painel lê os e-mails da caixa de entrada para separar propostas de trabalho e permite responder essas mensagens a partir do próprio painel. Ele não apaga, não move e não altera e-mails.
  • Instagram (@ryalvz): o painel lê as métricas da própria conta profissional (alcance, visualizações, interações, seguidores e desempenho dos posts).

Como os dados são usados

Os dados são usados só para mostrar essas informações ao próprio Ryan Alves dentro do painel. Eles não são vendidos, não são compartilhados com terceiros e não são usados para publicidade.

Onde os dados ficam

O conteúdo dos e-mails é lido na hora e não é guardado. As autorizações de acesso ficam guardadas de forma protegida no banco de dados do painel (Supabase), que só o dono acessa. O uso dos dados recebidos das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Como desfazer o acesso

O acesso pode ser desfeito a qualquer momento pelo botão "Desconectar" no painel, em myaccount.google.com/permissions (Google) ou nas configurações de apps do Instagram.
